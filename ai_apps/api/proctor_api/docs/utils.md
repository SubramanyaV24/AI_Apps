# Proctor API Utilities (utils)

## Overview
The `utils/` directory contains helper modules for checking authorization, logging, and validating incoming JSON payloads.

---

## 1. Authentication Helper (`auth.py`)
`auth.py` validates request headers against whitelist settings.

### Key Functions
#### `get_token_from_header() -> str`
- **Purpose:** Extracts the Bearer token from incoming request headers (`frappe.get_request_header('Authorization')`).
- **Raises:** `frappe.AuthenticationError` if headers are missing or the format is invalid.

#### `validate_token() -> None`
- **Purpose:** Compares the extracted Bearer token with the registered token.
- **Whitelist Lookup:** Checks the site configuration under `"proctor_api_token"` first, falling back to the environment variable `PROCTOR_API_TOKEN`.
- **Raises:** 
  - `frappe.AuthenticationError` if no token is configured on the server.
  - `frappe.PermissionError` if the bearer token is invalid.

## 2. Logger Helper (`logger.py`)
`logger.py` configures unified logging.

### Key Functions
#### `get_logger(module_name: str) -> logging.Logger`
- **Purpose:** Obtains a standardized logging instance pointing to standard Frappe logger `"proctor_api"`.
- **Output:** Streams messages directly to the active Frappe site logs and stdout.

## 3. Validation Helper (`validation.py`)
`validation.py` enforces payload requirements and schemas on incoming API endpoints.

### Key Functions
#### `validate_session_payload(data: Dict[str, Any]) -> None`
- **Purpose:** Asserts incoming sessions match parameters.
- **Checks:**
  - Requiring `candidate_id` and `exam_id`.
  - Asserts `started_at` follows standard ISO or `YYYY-MM-DD HH:MM:SS` format.
  - Verifies `ip_address` is a string.
- **Raises:** `frappe.ValidationError` on failures.

#### `validate_event_payload(data: Dict[str, Any]) -> None`
- **Purpose:** Asserts incoming events match criteria.
- **Checks:**
  - Requiring `session` and `event_type`.
  - Confirms the associated `Proctor Session` ID exists in the database.
  - Verifies that `confidence_score` is a numeric value bounded between `0.0` and `1.0` inclusive.
- **Raises:** `frappe.ValidationError` on failures.
