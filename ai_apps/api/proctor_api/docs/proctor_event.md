# proctor_event.md

## Overview
`proctor_event.py` implements the **Proctor Event** CRUD API for the AI Apps Proctoring system.  It provides a set of `@frappe.whitelist` functions that are callable from the frontend or from external ML services.  The module handles:
- Validation of incoming JSON payloads.
- Creation of a parent **Proctor Event** document and child **Proctor Session Event** rows.
- Specialized helpers for session start, full‑session batch events, and generic event retrieval/modification.
- Robust error handling, dead‑lock retries, and detailed logging.

The functions are deliberately **guest‑allowed** (authentication is performed via a token‑validation helper) to allow the ML server to submit events without a logged‑in user.

## Common Patterns & Security Notes
- **Input Validation** – All public functions wrap payload parsing in a `try/except` block and log errors via `frappe.log_error`.  Missing required fields raise `frappe.exceptions.ValidationError` with a clear message.
- **Race‑Condition Guarding** – When creating a parent event (`create_event`, `create_start_event`, `create_full_session_event`) the code attempts an insert and catches `frappe.DuplicateEntryError` to rollback and fetch the already‑created parent.
- **Dead‑lock & Lock‑Wait Handling** – Each write loop retries up to a fixed number of attempts (`range(8)` or `range(5)`) with incremental back‑off (`time.sleep`).  This mitigates MySQL dead‑locks under high concurrency.
- **Metadata Normalisation** – Payload `metadata` may be a dict or JSON string; the code normalises it to a dict and stores the JSON string via `frappe.as_json`.
- **Logging** – Detailed `_logger.info` statements capture attempt numbers, session identifiers, and row‑count diagnostics after persisting.
- **Permission Model** – Functions are declared with `@frappe.whitelist(allow_guest=True)` but rely on the `validate_token` helper (imported elsewhere) to ensure the caller possesses a valid JWT or API token before processing.  This keeps the public endpoint safe while still usable by automated services.

## Example Usage (Python‑style pseudo‑code)
```python
import requests, json

# Submit a detection event from an ML service
event_payload = {
    "session": "session_123",
    "event_type": "VIOLATION",
    "severity": "HIGH",
    "penalty_points": 10,
    "metadata": {"source": "ML", "detector": "object_detection"},
    "timestamp": "2026-05-27T14:00:00"
}

resp = requests.post(
    "https://your-frappe-site/api/method/ai_apps.api.proctor_api.proctor_event.create_event",
    json=event_payload,
    headers={"Authorization": "Bearer <your-token>"}
)
print(resp.json())
```
