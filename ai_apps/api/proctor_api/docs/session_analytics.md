# session_analytics.md

## Overview
`session_analytics.py` implements the **Session Analytics API** for the Proctoring system. It provides whitelisted endpoints that expose aggregated analytical data about past Proctor Sessions, including session metadata, related events, evidence, and violation statistics.

## Key Endpoints

| Endpoint | Description |
|----------|-------------|
| `get_session_details(session_id)` | Returns full analytics for a single session: header information, event list, evidence list, and per‑severity violation counts. |
| `mark_reviewed(session_id)` | Marks a session as reviewed (`review_required = 0`). Intended for human reviewers; future RBAC will restrict access. |

## Implementation Details

### `get_session_details`
- **Input Validation**: Ensures `session_id` is a non‑empty string; throws a `ValidationError` otherwise.
- **Session Header**: Retrieves the `Proctor Session` document via `frappe.get_doc`.
- **Events**: Looks up the parent `Proctor Event` for the session and fetches all child rows (`Proctor Session Event`) ordered by `occurred_at`.
- **Evidence**: Queries `Proctor Evidence` linked to the session, ordering by `captured_at`.
- **Violation Counts**: Filters out `SESSION_START` and `SESSION_END` events and aggregates counts per severity (`high`, `medium`, `low`).
- **Response**: Returns a JSON‑compatible dict containing `session`, `events`, `evidence`, and `violation_counts`.

### `mark_reviewed`
- **Input Validation**: Checks that `session_id` is a valid string.
- **Existence Check**: Confirms the session exists.
- **Update**: Sets `review_required` to `0` on the `Proctor Session` doctype, commits the transaction, and returns `{ "success": true }`.
- **Security Note**: TODO comment marks the need for role‑based access control (e.g., `Proctor Reviewer`).

## Security Considerations
- All DB queries use Frappe ORM with parameterised filters to prevent SQL injection.
- Endpoints are currently exposed as `allow_guest=True`; future work should restrict access via proper permissions.
- Input validation guards against malformed or missing parameters.
