# RiskBadge Component

## Overview
`RiskBadge.jsx` provides a small, color‑coded badge indicating the risk level of a Proctor session. It accepts a single `risk` prop (string) and renders a `<span>` with appropriate CSS classes defined in `RiskBadge.css`.

## Props
- **risk** (string, required): Expected values are `"low"`, `"medium"`, `"high"`, or `"critical"`. The component normalises the value to lower‑case and falls back to `"low"` if missing.

## Styling
The badge uses the `risk-badge` base class and a modifier class `risk-{level}` (e.g., `risk-low`). Colors are defined in `RiskBadge.css`.

## Usage Example
```jsx
import RiskBadge from './RiskBadge';

function SessionRow({ session }) {
  return (
    <div className="session-row">
      <h3>{session.title}</h3>
      <RiskBadge risk={session.risk_level} />
    </div>
  );
}
```

## Security Notes
- The component does **not** use `dangerouslySetInnerHTML`; React automatically escapes any dynamic text, preventing XSS.
- All props are validated with `prop-types`.
