# table.md

## Overview
`table.jsx` provides a minimal set of **Shadcn UI‑style** table components for the Proctor Dashboard front‑end. These components are lightweight, framework‑agnostic React primitives that wrap native HTML table elements with Tailwind‑like utility classes for a clean, dark‑theme compatible look.

## Exported Components

| Component | Description | Props | Example Usage |
|-----------|-------------|-------|----------------|
| `Table` | Root wrapper that adds horizontal scrolling and a full‑width table element. | `className` (optional string) – additional CSS classes; `children` – table markup. | `<Table className="my-table"><TableHeader>…</TableHeader><TableBody>…</TableBody></Table>` |
| `TableHeader` | Renders `<thead>` with a semi‑transparent dark background. | `className`, `children` | `<TableHeader><TableRow>…</TableRow></TableHeader>` |
| `TableBody` | Renders `<tbody>` with subtle row dividers. | `className`, `children` | `<TableBody><TableRow>…</TableRow></TableBody>` |
| `TableRow` | Simple `<tr>` wrapper. | `className`, `children` | `<TableRow><TableCell>Data</TableCell></TableRow>` |
| `TableHead` | Renders a `<th>` cell with padded styling. | `className`, `children` | `<TableHead>Column</TableHead>` |
| `TableCell` | Renders a `<td>` cell with padded styling. | `className`, `children` | `<TableCell>Value</TableCell>` |

## Styling Notes (Tailwind‑like classes)
- **Container:** `w-full overflow-x-auto` ensures the table stretches to the parent width and scrolls on overflow.
- **Table:** `border-collapse text-sm text-left` provides a compact layout.
- **Header:** `bg-gray-800/50` matches the dark theme used throughout the dashboard.
- **Body:** `divide-y divide-gray-700` adds subtle horizontal dividers.
- **Cells:** Padding (`px-4 py-2`) gives a comfortable click target and visual spacing.

## Usage Example (JSX)
```jsx
import { Table, TableHeader, TableBody, TableRow, TableHead, TableCell } from './ui/table';

function SessionsTable({ sessions }) {
  return (
    <Table className="border border-gray-700">
      <TableHeader>
        <TableRow>
          <TableHead>ID</TableHead>
          <TableHead>User</TableHead>
          <TableHead>Status</TableHead>
        </TableRow>
      </TableHeader>
      <TableBody>
        {sessions.map(s => (
          <TableRow key={s.name}>
            <TableCell>{s.name}</TableCell>
            <TableCell>{s.user_name}</TableCell>
            <TableCell>{s.status}</TableCell>
          </TableRow>
        ))}
      </TableBody>
    </Table>
  );
}
```
