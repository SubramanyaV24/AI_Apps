# TrustScoreCircle Component

## Overview
`TrustScoreCircle.jsx` renders a circular progress indicator visualising a **trust score** (0‑100). It uses SVG circles to draw a background track and a foreground arc whose length and colour correspond to the score.

## Props
- **score** (`number`, required) – The trust score to display. Values are clamped to the range 0‑100.

## Rendering Logic
1. **Normalization** – `normalizedScore = Math.min(Math.max(score, 0), 100)` ensures the value stays within bounds.
2. **SVG Geometry** – Radius = 36 px, stroke width = 4 px. The circumference is computed as `2 π r`.
3. **Arc Length** – The `strokeDashoffset` is set to `circumference - (circumference * normalizedScore) / 100` to create a partial circle representing the score.
4. **Dynamic Colour** – `getColor()` returns:
   - `#10b981` (green) for scores ≥ 80
   - `#f59e0b` (orange) for scores ≥ 50
   - `#ef4444` (red) otherwise.
5. **Center Text** – The numeric percentage is rendered inside the circle, coloured the same as the arc.

## Styling (TrustScoreCircle.css)
- `.trust-score-bg` – background track colour (`#1e293b`).
- `.trust-score-fg` – foreground arc colour (set via inline `stroke` attribute). The CSS file also contains any needed `stroke-linecap: round` for a smooth end.

## Security Notes
- No user‑generated HTML is injected; the component only renders numeric text, which React safely escapes.
- PropTypes enforce that `score` is a number, reducing the risk of type‑confusion attacks.
- All SVG attributes are static or derived from a numeric value; there is no `dangerouslySetInnerHTML`.

## Usage Example (JSX)

function SessionTrust({ session }) {
  return (
    <div className="trust-score-wrapper">
      <h4>Trust Score</h4>
      <TrustScoreCircle score={session.trust_score} />
    </div>

}
