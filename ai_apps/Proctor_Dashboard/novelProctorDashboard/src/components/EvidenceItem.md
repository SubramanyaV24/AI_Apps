# EvidenceItem Component

## Overview
`EvidenceItem.jsx` renders a single piece of evidence (screenshot or audio) attached to a Proctor session. It resolves relative SharePoint URLs using the base URL from `proctorApi` and safely displays the appropriate HTML element.

## Props
- **evidence** (object, required) – Shape:
  - `evidence_type` (string) – `'screenshot'`, `'audio'`, or other.
  - `sharepoint_url` (string, required) – URL to the original file.
  - `thumbnail_url` (string, optional) – For screenshots, a preview image URL.

## Rendering Logic
- If `sharepoint_url` is missing, the component renders nothing.
- For **screenshot** evidence with a thumbnail, it renders an `<img>` element.
- For **audio** evidence, it renders an `<audio>` element with controls.
- For any other type, it falls back to a generic link.

## Security Notes
- URLs are resolved via `proctorApi.frappeBaseUrl` only when they start with `/`, preventing accidental absolute URL injection.
- React automatically escapes any text content; no use of `dangerouslySetInnerHTML`.
- PropTypes enforce required fields, reducing the risk of undefined values.

## Usage Example
```jsx
import EvidenceItem from './EvidenceItem';

function EvidenceList({ evidences }) {
  return (
    <div className="evidence-list">
      {evidences.map((ev, idx) => (
        <EvidenceItem key={idx} evidence={ev} />
      ))}
    </div>
  );
}
```
