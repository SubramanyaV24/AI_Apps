# ProctorDashboard Component

## Overview
`ProctorDashboard.jsx` is the primary dashboard interface orchestrating live proctoring monitoring. It serves two monitoring modes:
- **Local Webcam Mode:** Triggers user webcam/mic capture via the client‑side `Autoproctor` monitor. Performs client‑side frame capture and triggers periodic calls to the backend ML service for face tracking, gaze direction, multi-speaker recognition, and suspicious object detection (e.g. mobile phones).
- **Remote Candidate Mode:** Polls the Frappe backend for screenshots, audio segments, and events belonging to another candidate's active session, enabling remote review/proctoring of active tests.

## Key Features
- **Integrated ML Pipeline** – Transmits base64 camera frames and audio buffers asynchronously to the ML endpoints (`runAllAnalysis` and `analyzeAudio`).
- **Real-Time Bounding Boxes** – Renders canvas-mapped overlays displaying bounding boxes for detected faces, body segments, and YOLO object detections (e.g., cell phones).
- **Security Violation Logger** – Collects events locally and pushes them to `evaluateEvent`. Updates overall trust score and risk classification dynamically.
- **Evidence Management** – Captures video frames and audio (converted from PCM to WAV) and uploads them to SharePoint via `uploadEvidence`.
- **Session Lifecycle Controls** – Supports creating, running, ending, and submitting exams, including batch event uploads.
- **Resilient Fallback** – Displays diagnostic statistics (ML latency, detector name, and connectivity alerts).

## Component Structure & Logic Flow
1. **Startup Health Check:** Performs startup checks on the ML service to verify backend integration.
2. **Local Webcam Loop:**
   - Enumerates available video input devices.
   - Instantiates an `Autoproctor` instance upon clicking **Start Session**.
   - Registers listeners for:
     - `face-update` → sets raw streams to video element.
     - `violation` → captures canvas frames and dispatches to backend.
     - `audio-buffer` → pipelines mono audio samples to state queue.
3. **ML Frame Loop:** Fires every `750ms` when active. Draws mirrored camera frames to a hidden `<canvas>`, extracts base64 JPEGs, fetches buffered audio arrays, and fires concurrent requests to ML backend modules.
4. **Remote Poller:** If in **Remote** mode, periodically fetches active sessions list and queries `getSessionDetails` every 3 seconds to fetch screenshots and update event summaries.
5. **Session Teardown:** Closes local hardware captures, submits end payloads, updates Frappe status, and triggers a full batch sync.

## Security Considerations (per SecureCoder rules)
- **Safe Output Rendering:** Evaluates raw event descriptions and metadata dynamically using React JSX (prevents standard XSS vectors).
- **PCM WAV Conversion:** Conversions occur locally in memory (`pcmToWavDataUri`) using typed `DataView` operations without invoking external code compilers or format scripts.
- **Media Security:** Limits media sources strictly to user-configured inputs and handles permission denials gracefully.
- **Telemetry Protection:** Uses JWT/session token validations via API wrappers for all administrative mutations.
